#### 2. **Rate Limit Logic Gap** (Confidence: 82%)

**File:** `drep/adapters/gitlab.py:210`
**Issue:** Rate limit check raises error only when `remaining == 0`, but GitLab might return 429 status even when `RateLimit-Remaining` is not exactly 0.

**Current Logic:**
```python
# Lines 185-186: Return early if NOT 429
if response.status_code != 429:
    return

# Lines 203-221: Only raise if remaining == 0
# GAP: What if 429 with remaining != 0?
```

**Fix:** Ensure 429 always raises error, regardless of header parsing:
```python
def _check_rate_limit(self, response: httpx.Response, owner: str = "", repo: str = "") -> None:
    if response.status_code != 429:
        return

    # If we got 429, we're rate limited - always raise
    # Parse headers for better error message, but don't depend on them
    remaining_str = response.headers.get("RateLimit-Remaining")

    # ... (existing parsing logic)

    # Always raise for 429, even if header parsing fails
    raise ValueError(f"GitLab API rate limit exceeded ...")
```

**Priority:** P0 (production reliability)

#### 6. **Type Design Inconsistency** (Rating: 6/10)

**File:** `drep/models/config.py`
**Issue:** `GitLabConfig` uses `Optional[str]` for URL, while `GitHubConfig` uses `HttpUrl` with default.

**Comparison:**
| Adapter | URL Type | Default | Validation |
|---------|----------|---------|------------|
| Gitea | `str` (required) | None | None |
| GitHub | `HttpUrl` (optional) | `https://api.github.com` | Pydantic validates |
| GitLab | `Optional[str]` (optional) | `None` (magic value) | **None** ❌ |

**Issue:** Magic `None` value means "use GitLab.com" but type doesn't express this. Invalid URLs (`ftp://...`) accepted at config time, fail later.

**Recommended Fix:**
```python
class GitLabConfig(BaseModel):
    url: HttpUrl = Field(
        default="https://gitlab.com/api/v4",
        description="GitLab API URL (default: gitlab.com, or custom for self-hosted)"
    )
    token: SecretStr = Field(...)
    repositories: List[str] = Field(...)
```

**Priority:** P1 (consistency, fail-fast)
